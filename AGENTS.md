# openOODA (.oo) Agent Quick Card
1. **The 8 Canonical Quick Cards**: `ooda ooda|layers|spec|rules|ui|security|privacy|defense`.
2. **Power-of-2 Shape Ladder (`1/2/4/8/16/32/64/128/256`)**:
   - `1`: 1 link count, max 1 stmt/line. `2`: `tests/test_functional.oo` + `tests/test_refusal.oo`.
   - `4`: Max 4 nesting depth. `8`: Max 8 files/dir, 8 fns/file, 8 params/fn.
   - `16..256`: 16-256 lines/file (shims exempt), max 64 lines/fn, max 128 chars/line.
3. **Syntax & UI**: Relative string imports only, COSMIC shell/4-menu standard (`Screenshot`), `fb_cli_run` + `fb_modal`.
